# 浓香型白酒香气数据库（26年3月）

从 27 篇文献的长表数据整合出的**浓香型白酒香气物质宽表数据库**，并完成阈值匹配、OAV 核算、可用数据判定与多元统计分析（PCA + 层次聚类）。

> 完整的方法、决策依据与结论见 **[`会话上下文导出.md`](会话上下文导出.md)**（机器可读版：`会话上下文导出.json`）

---

## 关键结果

- 单位统一 **μg/L（≡ ppb）**；9 篇文献（D5/D9/D10/D11/D12/D14/D19/D22/D24）原文为 mg/L，×1000 换算
- 阈值匹配 **152/373**；缺阈值 221（周表未收录 135 / 无中文名 48 / 无名行 38）
- 可算 OAV **4581** 格，**OAV>1 = 2042（44.6%）**，113 个样品列全部含有效数据
- PCA：PC1 31.8%（总体香气强度，与 log10 总浓度 r=0.60）、PC2 19.3%（醇类 vs 酯类）
- 聚类：化合物分"醇/酸块"与"酯块"，样品基本按文献成簇（方法/单位/样品类型差异）

环境：Python 3.12 / pandas 2.2 / openpyxl 3.1 / scikit-learn 1.5 / scipy 1.13 / matplotlib 3.9 / seaborn 0.13

## 注意

- `ppb = μg/L`（水溶液基准）；OAV 无量纲，不乘单位因子
- 原库 `Threshold（μg/L）` 与周表 `阈值(ppb,周表)` 为**两套不同来源**，数值可能相差一个数量级
- 缺阈值 ≠ 不可用：135 个有数据的化合物补上阈值后可重新判定
- 同一化合物存在多行记录（辛酸乙酯、戊酸乙酯、癸酸乙酯、4-乙基苯酚等），合并时取并集
